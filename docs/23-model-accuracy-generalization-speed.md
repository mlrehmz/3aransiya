# Model research for the expanded Darija corpus

**18 November 2026 · Recommendation before the v2 training run**

The current encoder–decoder leads overall validation at 81.19% strict. GRU/CTC leads the original unseen slice at 56.21%. Development checks identified errors on new spellings, French loans, and a short MSA phrase. CPU latency and runtime causes had yet to be measured at this stage. The following experiments keep those outcomes separate. [Six-epoch validation](18-six-epoch-colab-comparison.md) · [Spelling checks](20-darija-correction-set-draft.md)

## First isolate the dataset change

- Train the existing encoder–decoder and GRU/CTC on the same screened v2 data using the current FP32 AdamW setup. Keep the initial learning rate, clipping, batch size, and seed fixed. Validate after each epoch. Record optimizer updates and elapsed time because a v2 epoch is much larger. Inspect one full pass before committing to another six-epoch run. AdamW provides a standard baseline, and an optimizer swap would make the first data comparison harder to interpret. [AdamW paper](https://arxiv.org/abs/1711.05101)
- Preserve NFC, case, Arabizi digits, and written Arabic base letters. Keep `p` → پ, `x` → ش, and similar choices as supervised examples in the relevant contexts. Global substitutions would collapse valid readings such as names and emphatic letters. Keep human and synthetic provenance available. Human v1 contributes **13.35%** of the expanded training occurrences, so report the actual proportion presented to the models. If the all-data run regresses on common forms, compare a more human-weighted mix at the same update budget. Prior work on synthetic training data supports tracking its provenance, though machine-translation results do not establish the best ratio for Darija. [Tagged back-translation](https://arxiv.org/abs/1906.06442) · [Arabizi orthographic variation](https://aclanthology.org/2014.amta-researchers.25/)
- Keep the original validation rows and v1-defined common and unseen slices. In the v1 unseen slice, 677 of 3,389 occurrences now have an exact Latin form in v2 training and 2,712 are still unseen. Report those two groups separately. This distinguishes gaining examples of the spelling from generalizing to a spelling still absent from training. Keep the approved spelling probes and MSA phrases as separately reported development checks.
- The v2 alphabets contain 85 input and 60 output characters. Rebuild the ordered vocabulary rather than loading a v1 checkpoint by index. Preflight **both** candidates with the same eligibility rules. Only two v2 occurrences exceed the existing nine-frame CTC budget. Both have a one-letter Latin `l` paired with a full Arabic word containing the attached preposition. Review these as alignments before increasing frame expansion for every input. [CTC paper](https://doi.org/10.1145/1143844.1143891)

## Architecture experiments after the v2 baseline

| Goal | Recommended experiment | Evidence and limitation |
| --- | --- | --- |
| Better spelling fidelity | Add single-head dot-product attention to the existing GRU decoder while retaining bounded greedy output. | The current decoder sees the encoder's terminal states. Attention lets it use individual input positions. A character GRU with attention has direct Arabizi precedent at the utterance level. Measure the cost of attention on this CPU before adopting it. [Arabizi sequence-to-sequence study](https://aclanthology.org/2020.wanlp-1.15/) |
| Faster warm predictions | Compare the existing one-pass GRU/CTC with a small temporal convolutional encoder using the same CTC output head. | CTC avoids sequential output decoding. A faster encoder is a plausible experiment. Published gains for translation are not a latency estimate for an 18-character word on the i5. [Non-autoregressive CTC study](https://aclanthology.org/D18-1336/) |
| Additional quality | Consider a small character Transformer if both GRU paths stop improving. | Transformers improved character transliteration on external tasks. Their parameter counts, task distributions, and decoding costs differ from this scratchpad. [Character-level Transformer study](https://aclanthology.org/2021.eacl-main.163/) |

Maintain a word-level fast path. MSA expressions also need phrase-level checks because a correct rendering may join conjunctions and attached clitics. Compare reviewed phrase examples and spacing independently. Consider a small context-aware model or MSA pretraining only if those tests show a persistent gap after the Darija baseline. Context-aware Arabizi systems and annotation work provide precedent for evaluating that problem at utterance level. [Arabizi utterance model](https://aclanthology.org/2020.wanlp-1.15/) · [Arabizi token alignment and clitics](https://aclanthology.org/W14-3612/)

## Measure the delay users feel

At a separately approved benchmark step, time cold helper startup, warm batch-one model inference, the persistent pipe round trip, and separator-to-Arabic-output latency on Fedora. Use a single thread and include short and longest supported inputs. Compare medians and tail percentiles using the same inputs on both models. The current helper starts on the first request, so a slow first word could arise before either model runs. Warm the helper after app launch if cold startup dominates. Simplify the batch-one path or test a supported quantized build only if warm model time dominates, and verify any optimization against unchanged output tests. [PyTorch benchmarking utilities](https://docs.pytorch.org/docs/2.11/benchmark_utils.html)
